# BookHub

BookHub is a web-based online bookstore application designed to connect readers with independent booksellers and a vast collection of books. It features a dynamic catalog, user account management, and an administration interface for inventory control.

## Features

### User Features
*   **User Authentication:** Secure signup and login functionality with password hashing.
*   **Browse & Search:** View "Best Selling" and "New Release" sections, or search for books by title, author, or keywords.
*   **Categorization:** Filter books by specific genres (Horror, Fiction, Biography, etc.) and sort by title.
*   **Book Details:** Access detailed pages for each book containing descriptions, publication info, and author details.
*   **Digital Downloads:** Registered users can download PDF versions of available books.
*   **Profile Management:** Users can update their personal details (name, email, password) or delete their account.

### Admin Features
*   **Inventory Management:** Admin dashboard to add new books to the database.
*   **Metadata Management:** Capability to add and manage authors, publishers, and genres dynamically.
*   **File Uploads:** Upload book cover images and PDF files directly through the admin panel.

## Technologies Used

*   **Frontend:** HTML5, CSS3, JavaScript (ES6+)
*   **Backend:** PHP (Vanilla)
*   **Database:** MySQL
*   **Design:** Responsive layout with custom CSS and FontAwesome icons.

## Usage

*   **Visitors:** Can browse the catalog, view book details, and search.
*   **Registered Users:** Can do everything a visitor can, plus download book PDFs and manage their profile.
*   **Admins:** Access the `admin.php` page (requires an account with type 'admin') to upload new content.
